# 星星打卡

面向 iPad 的中文每日任务和累计星星奖励应用。独立实现，无需账户，不接入广告、分析或云端数据服务。

## 1.3.0 · 家长密码与统一入口

- “家长设置”成为唯一管理入口，打开时需要 4 位密码；初始密码为 1234，可在记录与备份中修改。
- 首页不再显示“设置奖励”和备份入口，任务、奖励、删除及备份统一放在家长设置中。
- 家长设置中的任务和奖励支持删除；删除前说明影响并再次确认。

- 自定义、编辑、暂停和恢复任务；每项任务每天完成一次，增加一颗星。
- 默认英语、数学、语文；初始星星为零。
- 可取消今天的打卡并扣回一颗星，取消后可重新完成；已领取奖励保留记录。
- 阶段奖励按历史累计星星解锁，每项仅领取一次，领取不扣星星。
- 任务暂停或改名不删除历史记录，也不会重置当天限制。
- 本地保存，JSON 导出与恢复；恢复前有明确确认。
- 响应式界面、主屏幕图标、联网加载后的离线缓存（需 HTTPS 或 localhost）。

## 使用

通过 HTTP/HTTPS 服务访问 dist/。iPad 使用 Safari 打开正式网址，选择「分享 → 添加到主屏幕」，此后从同一个主屏幕图标进入。

记录按网站地址及浏览器分别保存；电脑、iPad 与不同网址之间不会同步。清除网站数据、无痕浏览或移除后清理网站存储可能丢失记录，请定期在家长设置中导出备份。首次添加到主屏幕后若记录未出现，可导入原备份。

局域网预览需电脑运行服务，iPad 与电脑处于同一 Wi-Fi。正式托管不依赖电脑常开。托管平台的访问权限与应用本身的免登录模式是两回事，公开免登录访问需将网站观众设置为公开。

日期以设备本地日期为准，跨零点后自动更新，每 15 秒及切回前台检查。没有云端时间校验，也没有防止人为修改系统日期的功能。家长密码保存在当前设备，用于避免孩子误改设置，不属于高强度安全保护。
